PulseCare Clinic Portal

Smart Clinic Operations & Patient Appointment Scheduling with ASP.NET Core MVC & SQLite

Course: Web Technologies with .NET
Evaluation: Mini Project & Poster Presentation
Architecture: Model-View-Controller (MVC)
Database: SQLite + Entity Framework Core

Problem Statement

Conventional polyclinics and diagnostic practices frequently face severe administrative bottlenecks due to manual paper registers and verbal phone bookings:
  • Prolonged Patient Wait Times: Unregulated walk-in traffic causes crowded clinic lobbies.
  • Double-Bookings & Slot Clashes: Lack of real-time scheduling checks creates overlapping doctor visits.
  • Scattered Patient Histories: Misplaced physical case records hamper doctor consultations.
  • Manual Revenue Tracking: Tedious daily reconciliation of consultation fees and patient volumes.

Core Objectives

  • Digital Slot Allocation: Multi-department scheduling allowing patients to select doctors and book real-time available consultation windows.
  • Full CRUD Lifecycle: Comprehensive Create, Read, Update, and Delete operations for managing doctors, patient profiles, and appointments.
  • Dual Model Validation: Data Annotations enforcing client-side and server-side integrity (past-date prevention, phone/email format, required fields).
  • State-Driven User Context: In-memory Session management for role authorization and TempData flash banners for booking feedback.

Technology Stack

Session & TempData State Management

System Architecture (MVC)

+-------------------------------------------------------------+ | PRESENTATION TIER | | Razor Views (.cshtml) + Bootstrap 5 + Client Validation | +------------------------------+------------------------------+ | HTTP GET/POST (AntiForgery) v +-------------------------------------------------------------+ | APPLICATION TIER | | ASP.NET Core Controllers: Home, Appointments, Doctors, | | Account + Session Middleware & TempData State | +------------------------------+------------------------------+ | LINQ Queries / Model Binding v +-------------------------------------------------------------+ | PERSISTENCE TIER | | Entity Framework Core (SQLite Provider) | | Entities: Doctor, Patient, Appointment, Department, User | +------------------------------+------------------------------+ | File Storage v +-------------------------------------------------------------+ | DATABASE TIER | | SQLite Relational Database (`pulsecare.db`) | +-------------------------------------------------------------+

Implemented Modules

  • Operational KPI Dashboard: Real-time aggregation of pending approvals, confirmed appointments, active medical staff, and consultation revenue.
  • Doctor Directory & Departments: Filterable catalog across Cardiology, Dermatology, Pediatrics, Orthopedics, and General Medicine.
  • Slot Booking & Form Handling: Interactive booking engine with dynamic time-slot pickers and automated patient account association.
  • Clinical Records & Print Slip: Diagnostic notes and prescription logging with browser print stylesheet for physical token slips.
  • Role-Based Session State: Dedicated Admin vs. Patient session contexts with flash feedback notifications.

Key Results & Benchmarks

  • Zero Slot Collision: Relational foreign key integrity in EF Core prevents conflicting appointments.
  • Instant Query Latency: Embedded SQLite file engine executes queries in <10 ms with zero external server overhead.
  • 100% Mobile Responsive: Fluid layout on smartphones, clinic front-desk tablets, and desktop workstations.
  • Stateful User Experience: Seamless login tracking and instant feedback banners without page flickering.

Conclusion & Future Scope

PulseCare establishes a production-grade template for modern clinic management by combining ASP.NET Core MVC's robust separation of concerns with EF Core and SQLite's lightweight relational reliability.
Future Scope: WhatsApp automated reminder webhooks (Twilio), online consultation prepayments (Razorpay UPI), and integrated telemedicine video rooms.
